# Reliktinseln Mini

Kleines Mobile-PWA-Spiel im Hochformat: du hast eine Insel, sammelst durch Tippen, baust, die Insel wird sichtbar *deine*. Relikte sind Belohnungsmomente, nicht das ganze Spiel.

## Constraints

- Mobile First, Hochformat, Touch First, PWA, offline spielbar
- Lokales Savegame, keine Accounts
- Kein Backend, kein Multiplayer, keine Werbung, keine In-App-Käufe
- Privates Repo, nicht veröffentlichen
